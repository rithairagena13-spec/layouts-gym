Exercise 3: Comment List

A media-object layout with avatars that do not shrink when comment text is long.

I really enjoyed this project. The layout is clear, and the examples make it easy to understand how flexbox works.

This is a longer comment to demonstrate the media-object pattern. When a comment contains several sentences, detailed explanations, suggestions, and feedback about a project, the text needs enough space to wrap naturally while the avatar keeps its original size. The flex layout should allow the text to occupy the remaining space without squeezing the avatar. Using shrink-0 on the avatar ensures that the image or avatar stays consistent even when the content becomes much longer. This makes the comment section more readable and keeps every comment aligned properly on the page.
